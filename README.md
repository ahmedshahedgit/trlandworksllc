# Build a Premium Luxury Website for T&R Landworks LLC

Create a complete, production-quality website for **T&R Landworks LLC**, a fully insured land clearing, excavation, grading, drainage, storm cleanup, and property/site work company serving **Muscle Shoals, Alabama and surrounding areas**.

## TECH STACK — REQUIRED

Build the website using:

* **React**
* **Vite**
* **TypeScript**
* **Tailwind CSS**
* **Framer Motion** for animations
* **Lenis** for smooth scrolling

Do NOT use Next.js, Bootstrap, or another framework.

Use a clean reusable component architecture and keep the code easy to maintain.

---

# DESIGN DIRECTION

The website must feel:

**Luxury + Premium + Rugged + Modern + Professional + Architectural**

Do NOT make it look like a generic construction template.

The visual direction should feel like a high-end creative agency designed the website specifically for an established landworks/excavation company.

Use:

* Large editorial typography
* Strong visual hierarchy
* Cinematic imagery
* Generous whitespace
* Premium spacing
* Dark graphite surfaces
* Warm ivory typography
* Restrained champagne/bronze accents
* Subtle borders
* Sophisticated motion
* Layered gradients
* Subtle grain/noise texture
* High-quality image compositions

Avoid excessive gold, excessive gradients, cartoonish graphics, excessive glassmorphism, or flashy animations.
